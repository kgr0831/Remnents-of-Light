# 1부. 기획안 원문 (발췌)

기획안에서 초월을 언급하는 곳은 **4개 파일 5군데**가 전부다. 원문 그대로 옮긴다.

### 1-1. 현상의 정의 — `세계관_및_고유명사_설정.md:60~70`

> **초월과 폭주 (Transcendence & Rampage) — 두 가지 극한의 진화**
>
> 이 세계의 개체들이 '빛'을 받아들이는 두 가지 상반된 극단적 현상입니다. 이 현상은 주인공만의
> 전유물이 아니라, 세계관 내의 모든 생명체와 기계들에게서 관찰되는 보편적인 법칙입니다.
>
> - **폭주 (빛 흡수)**: 빛에 굶주린 하층부의 짐승들이 빛을 강제로 빨아들였을 때 일어나는 현상입니다.
>   이성은 붕괴하지만, 육체가 비대해지고 원초적인 파괴력과 맷집이 극도로 상승하여 거칠고 묵직한
>   전투를 벌이게 됩니다.
>
> - **초월 (빛 방출)**: 성소의 정제된 기계나 강화 인간들이 체내의 빛을 고압력으로 뿜어낼 때 발생하는
>   현상입니다. 육체의 한계를 벗어나 초인적인 가속력을 얻게 되며, 찰나의 시간 속에서 움직이는 듯한
>   정교하고 빠른 속도전을 구사합니다.
>
> 주인공(버려진 집행관)이 지닌 가장 큰 특이점은, 이 **두 가지 상태(야만적인 폭주와 초인적인 초월)를
> 부작용 없이 자유자재로 스위칭**하며 싸울 수 있는 전무후무한 존재라는 것입니다.

### 1-2. 기능 명세 — `기능_구현_명세서.md:78~79`

### 1-3. 자원의 정의 — `세계관_및_고유명사_설정.md:46~47`

> **빛 (Prima Lux) — 절대적 생명 자원**
> 단순한 조명이 아닌, 물리적인 힘과 생명력을 지닌 이 세계의 근원적인 에너지 물질. 무기물에 주입되면
> 무한한 동력을 제공하고, 유기물에 주입되면 세포 재생과 수명 연장을 일으킵니다.

# 2부. 2026-08-02 확정 스펙

## 2-1. 지시 원문

> "광원이 100%일 때 발동되어, 70%가 될 때까지 유지되며 초월상태가 유지되는 동안 마스킹 시트에 따른
> cyan 색상 블룸이 플레이어에게 적용됩니다.(폭주 시스템의 블룸과 색상만 다름.) 또한 이제 적의 미래
> 공격 범위를 시각화 하여 볼 수 있게 됩니다."

> "폭주와 초월은 조건 달성 후에 바로 되지 말고, 현재 어떠한 액션 또는 연출이 진행이 끝난 뒤에
> 되는 걸로 하자."

## 2-2. 확정 스펙 (한 장 요약)

| 항목 | 값 | 출처 |
|---|---|---|
| **진입 조건** | 광원 **100%** (`maxEnergy` 도달) | 지시 |
| **진입 방식** | **자동 — 발동 키 없음** | 지시 해석 (폭주와 대칭) |
| **진입 타이밍** | ⭐ 조건 성립 즉시가 아니라 **진행 중인 액션·연출이 끝난 뒤** | 지시 (2차) |
| **해제 조건** | 광원 **70% 이하** | 지시 |
| **해제 타이밍** | **즉시** (지연 없음) | 결정 — 2-4 참조 |
| **유지 비용** | 광원 **초당 6** 자연 감소 → 100→70이 **5.0초** | 결정 |
| **초월 중 광원 획득** | **그대로 획득** — 배율 없음. 싸우면 연장된다 | 결정 |
| **연출** | 마스크 기반 **cyan 상시 블룸** (폭주 붉은 블룸과 색만 다름) | 지시 |
| **정보** | 적의 **미래 공격 범위 시각화 — 예고형** | 지시 + 결정 |
| **폭주와의 관계** | 구조적으로 동시 성립 불가 (광원 0 vs 100) | 자동 |

### 광원 경제 안에서의 자리

```
   광원  0 ──────────────── 25 ──────────────── 70 ──────────── 100
        │◀── 폭주 ──▶│                          │◀── 초월 ──▶│
        진입          해제                       해제          진입
        (자동)        (때려서 벌면)               (드레인·소비)  (자동)
```

- **양 끝이 상태, 가운데가 평상시.** 자원 하나가 세 구간을 만든다.
- **폭주는 벌어서 탈출하고, 초월은 써서 끝난다** — 방향이 정반대라 행동 동기가 겹치지 않는다.
- **연장의 손익분기**: 드레인 6/s를 타격(+3)으로 상쇄하려면 초당 2타. 반면
  **패링(+25) = 4초 연장, 처형(+30) = 5초 연장** — 고난도 조작이 곧 지속시간이 된다.

## 2-3. 선택지가 있었던 결정 4건

| 질문 | 선택한 것 | 탈락한 대안 |
|---|---|---|
| 100% → 70%로 내려가는 방식 | **자체 드레인 6/s (≒5초)** | 드레인 없음(써야만 끝남) / 고정 시간 후 70으로 강제 세팅 |
| 초월 중 광원 획득 | **그대로 획득 — 싸우면 연장** | 획득 차단(지속시간 고정) / 0.25배 감소(폭주와 대칭) |
| 공격 범위 시각화 | **예고형 — 공격 시작 시** | 상시형(사거리만 항상 표시) / 둘 다(상시 옅게 + 예고 진하게) |
| 기획안의 흑백 + 슬로우 | **이번 범위 제외** | 슬로우 포함 / 흑백 포함 |

## 2-4. 진입 지연 — 판단 근거

**적용 대상은 초월과 폭주 둘 다.** (폭주는 이미 동작 중이므로 소급 적용 = 회귀 위험)

- **"진행 중"의 기준**: 새 개념을 만들지 않고, 이미 있는 정의를 쓴다 — 처형 · 일섬 발동 · 일섬 차지 ·
  대시 · 공격 · 회피 카운터 · 패링 모션 · 광원 소모(캐스팅) 8종.
- **공중 여부는 조건에 넣지 않는다** — 넣으면 낙하 중에 영원히 진입하지 않는다.
- **예약하지 않는다** — 매 프레임 조건을 다시 본다. 대기 중 광원이 회복되면 진입 자체가 취소된다.
- ⚠️ **해제는 미루지 않는다.** 폭주 해제 조건("광원 25% 회복")은 **전투 중에만** 성립하는데, 전투
  중이라는 건 공격 모션이 계속 서 있다는 뜻이라 해제가 사실상 영구 지연된다. 초월도 마찬가지로
  광원 70 미만인데 유지되는 공짜 연장 구간이 생긴다.

## 2-5. 검토로 정정된 것 5건 (2026-08-02, 코드 대조)

초안을 코드와 다시 대조해 잡은 것들이다. **2건은 그대로 만들었으면 기능이 잘못 동작했다.**

| # | 초안 | 실측 | 정정 |
|---|---|---|---|
| ① | 예고는 "판정 순간"(`thrustDuration × 0.85` = 0.102s)에 끝난다 | **피해 확정은 `hitTime + dodgeWindowPost` = 0.152s**, 이는 Thrust(0.12s)를 넘어 **Recover 중**이다 | 총 예고 **0.402초**, Recover 구간 포함. 초안대로면 원이 **실제 피격 0.032초 전에 사라진다** |
| ② | 적 스캔 0.25s (폭주 아웃라인과 동일) | 예고는 **0.402초짜리 단발 이벤트** — 0.25s 주기면 최대 62%가 날아간다 | 컬링만 0.25s, **예고 판정은 매 프레임** |
| ③ | "진행률 0.98 이상에서 끝났으면 터짐"으로 패링/피격 구분 | 패링은 Recover 중에도 성립한다 → **패링 성공인데 원이 터진다**(정반대 피드백) | 휴리스틱 폐기. 적이 **무효화 여부를 직접 노출**(패링·회피·적 피격 3경로) |
| ④ | 드레인을 "5초 후 70"으로 검증 | 원격 에디터 프레임 튐으로 초 단위 측정은 이미 실패한 방식 | **프레임 누적**(`Σdt × 6` ±1)으로 검증 |
| ⑤ | 예고 원을 위해 신규 셰이더가 필요 | 기존 `Custom/RampageOutline`이 "알파 마스크 + HDR 단색"을 이미 한다 | **신규 셰이더 삭제.** 채움은 스케일로 표현 → **에셋 편집이 0이 됨** |

# 4부. 이번에 안 하는 것 (스펙 보존)

나중에 잡을 때 그대로 쓸 수 있게 근거와 함께 남긴다.

### (a) 흑백 화면 + 슬로우모션 — `기능_구현_명세서.md:79`

- **흑백**: 기존 `GrayscaleRendererFeature`(회피 저스트용) 재사용. cyan 블룸은 보호 레이어라
  **흑백 위에서 청록만 살아남는** 그림이 자동으로 나온다 — 별도 작업 없음.
- **슬로우**: "**주변만** 느리게 + 플레이어는 정상"은 `timeScale`만으로 안 되고 플레이어 이동·
  애니메이터 속도에 역보정 배율이 필요하다. 별건 규모.

### (b) 초월 전용 버프 — "초인적인 가속력"

폭주가 7종 배율(피해·점프·이속·공속·넉백·히트스톱·쉐이크)을 가진 것과 대칭이면 초월도 속도 계열
배율을 가져야 한다. **넣는 순간 밸런스 실측이 필요해져 작업 성격이 달라진다.**

### (c) 초월 진입 순간 연출

폭주는 진입 순간에 하트비트(화면 펄스 + 카메라 펀치) + 글리치 프레임 1회를 재생한다.
초월의 대응물은 지시에 없어 만들지 않는다.

### (d) 적·보스의 초월 / 초월 과사용 추적자

`세계관_및_고유명사_설정.md:61` · `전체_몬스터_기획.md:1304`. 폭주의 같은 항목과 함께 연기 중.

| 1 | cyan 색상 | `(0.10, 0.95, 1.00)` | 대안: 마스크 실측 발광색 `(126,191,198)/255`가 세계관상 "빛의 색"이지만 채도가 낮아 탁하다 |
| 2 | 블룸 세기 | `_BloomBoost` **3.5** | 폭주는 5.0이지만 그건 화면이 완전 암전일 때 값이다. 초월은 평상시 밝기라 과포화 우려 |
| 3 | 예고 원 색 | HDR `(2.0, 0.35, 0.12)` 주황빛 적색 | 위험 표시의 관습. 대안은 초월의 cyan으로 통일 |
| 4 | 지속 5초가 적당한가 | 드레인 6/s | 초월의 가치(공격 예고)가 광원 소모의 체력 1칸보다 큰지 |
| 5 | 무한 연장이 문제인가 | 획득 배율 없음 | 문제면 폭주와 대칭인 획득 배율을 그때 추가 |
| 6 | 초월 상태의 HUD 표시 | 에너지 바 재스케일 + 색 | 선택 항목 — 없어도 기능은 완전하다 |
