**벽타기 설계 변경 (2026-08-04, 최종)**
초기엔 "높이로 벽인지 추정"(`IsClimbableWall`)했으나 얇은 플랫폼·이음매 예외가 계속 나와 폐기했다.
현재는 **레벨에서 명시적으로 지정한 `Wall` 레이어 콜라이더에만** 붙는다.

- 신규 `climbWallLayer`(기본 `Wall`) — 지형(`Ground`)은 아무리 높아도 벽이 아니다.
- 접지 상태의 낮은 턱 자동 걸어오르기(`TryStepUpShortWall`)는 **제거** — "플랫폼에 순간이동" 증상의 정체였다.
  자동으로 올라가는 건 이제 **벽타기 중에만**.
- 에디터 툴 `Tools/Level/Create Wall Collider` (Ctrl+Shift+W)로 벽면을 지정한다(isTrigger, 이동에 영향 0).

> ⚠️ **Map1에 실제 Wall 콜라이더가 아직 배치되지 않았다.** 배치 전까지 벽타기는 발동하지 않는다.

## 🔆 광원 · 폭주 · 자아 · 초월 · 시간 가속

이 프로젝트의 정체성에 해당하는 부분. **하나의 자원(광원)이 네 시스템을 물고 있다.**

```
광원 100% ──▶ 🌌 초월 자동 진입 ──(70%로 드레인)──▶ 해제
   ▲                                                  │
   │ 전투로 획득 (+3 타격 / +10 처치 / +30 처형)        │ 소모
   │                                                  ▼
광원 0% ───▶ 🩸 폭주 자동 진입 ──(25% 회복)──▶ 해제
                    │
                    └─▶ 🧠 자아 소모 ─▶ 0이면 화면 글리치 + 5초마다 HP 1칸
```

### 🔆 광원 (빛 에너지) — `maxEnergy = 100`

| 항목 | 값 / 동작 |
| --- | --- |
| 획득 | 적 타격 **+3** · 일반 공격 처치 **+10** · 처형 **+30** |
| 획득 연출 | 적 몸 주위에서 원형으로 튀어나와 **2차 베지어 궤적**으로 흡수되는 픽셀 VFX |
| 일섬 소모 | 홀드 진행도에 비례해 40까지 점진 소모, 10% 아래면 홀드 취소(환불 없음) |
| E홀드 소모 | 초당 25 · 25마다 HP 1 회복, 만체력이면 패링 실드 생성 |
| 피격 연출 | 카메라 쉐이크 0.18s/0.22 + 풀스크린 붉은 플래시 |

### 🩸 폭주 (Rampage)

- **진입**: 광원 0에서 **자동** · **해제**: `rampageExitEnergyPercent 25`% 이상 회복
- 발동 키가 존재하지 않는 자동 상태 (그래서 입력 정식화 B-1 트랙은 대상 소멸로 종결)
- 시야 제한(B-2): **어둠 렌더러 피처** + 적 실루엣 아웃라인(링+코어) + 지형 글리치 라인
- 폭주 중 광원 회복 **50% → 25%**로 페널티 · HUD 광원 바를 회복치 100 기준으로 재스케일
- 이동속도 ×1.2 · 공격속도 ×1.4 · Idle/Run/Jump가 Glitch 버전으로 자동 치환
- `[ASSERT] rampage_vision: PASS (11/11)`

### 🧠 자아 (Ego)

- **별도 바 없음** — HP 칸 위에 회색이 위→아래로 차오르는 `Fill Amount` 연출로 통합 (EgoBar 삭제)
- 자아 0 → **화면 전체 글리치**(`ScreenGlitchFx` + `ScreenGlitchFeature` + `ScreenGlitch.shader`)
- 자아 0 동안 **5초마다 HP 1칸** 감소 + 광원도 초당 5씩 서서히 감소

### 🌌 초월 (Transcendence)

| 항목 | 값 |
| --- | --- |
| 진입 / 해제 | 광원 **100%** 자동 진입 → **70%** 이하로 드레인되면 해제 |
| 드레인 | 초당 `2.4` (약 12.5초 지속) |
| 시각 | cyan 마스크 블룸 `_Color = (0.10, 0.95, 1.00)` |
| 핵심 기능 | **적 공격 예고 표시** + 적 Windup을 2.5배로 늘려 방향·범위를 일찍 확정 |
| 버프 | 이동속도 ×1.2 · 점프력 · 대시거리 · 패링/회피 판정 완화 |
| 진입 연출 | `TranscendBurstFx` 플래시 + 충격파 링 (1회성) |

> **적 공격 판정 구조가 이때 바뀌었다** — 예고 원과 실제 판정을 일치시키려고, 적의 피격·패링 판정을
> **창끝 한 점(원) → 밑동~창끝을 잇는 캡슐**로 확장했다. 전체 전투에 적용된 변경.

### ⏱️ 시간 가속 (Time Accel) — 2026-08-04 신규

- **Left Alt 토글**. `Time.timeScale = 0.4`로 세계 전체를 늦추고, 플레이어만 `×2.5`로 되돌린다.
- 비활성 시 배율이 **정확히 1**이라 평상시 코드 경로는 전혀 바뀌지 않는 게 이 설계의 안전판.
- 소모 초당 **7.2** (초월의 3배) · 광원 10%에서 강제 해제 · 잔상 수명 2배 빨리 소멸
- `Time.fixedDeltaTime`도 ×0.4 (안 줄이면 물리가 20Hz로 돌아 터널링 위험)
- 일섬 · 처형 · 광원소모 · 폭주 · 회피카운터 진입 시 **자동 해제**(`CanSustainTimeAccel`)
- `[ASSERT] time_accel: PASS (7/7)` — 보정 정확도 이동거리 오차 4.0%, 속도 오차 0.0%
