# docs/notion — 노션 발행용 원고

`task.md`(3,700줄)를 사람이 읽는 진행 현황판으로 재구성한 원고다.
각 파일 = 노션 페이지 1개. 아래 트리 그대로 올리면 된다.

## 페이지 트리

```
(발행 전 읽을 것)                  ← APPLY_PERMISSION.md — 권한 적용 + 발행 절차 + 문법 레퍼런스

Remnants of Light                  ← 00_MAIN.md      (기존 페이지에 덮어쓰기)
├── 🧩 시스템 구현 현황            ← 01_시스템-구현-현황.md
├── 🗓️ 개발 타임라인               ← 02_개발-타임라인.md
├── 🚧 남은 작업 & 알려진 이슈     ← 03_남은-작업과-알려진-이슈.md
├── 🛠️ 개발 인프라 & 워크플로      ← 04_개발-인프라와-워크플로.md
└── ⚠️ Unity 함정 노트             ← 05_Unity-함정-노트.md
```

## 발행 방법

**A. 자동 (권장)** — Notion MCP 도구가 허용된 세션에서.
절차·주의사항·확장 마크다운 문법은 전부 **[`APPLY_PERMISSION.md`](APPLY_PERMISSION.md)** 에 정리해뒀다.

> ⚠️ **원격 루프 모드에는 Notion MCP 도구가 아직 허용되어 있지 않다** (2026-08-04 기준).
> 사용자가 `APPLY_PERMISSION.md`의 1·2단계(허용 목록 추가 + executor 재시작)를 한 번 실행해야 한다.
> 루프 세션은 이걸 스스로 못 한다 — `Edit(*.py)`가 허용 목록 밖이고, executor 재시작은 자기 자신을 죽인다.

**B. 수동** — 각 파일 본문을 복사해 노션 페이지에 붙여넣기.
노션은 마크다운 붙여넣기를 지원하므로 제목·표·목록·인용·구분선이 그대로 블록으로 변환된다.
(각 파일의 맨 위 H1은 노션 페이지 제목으로 들어가므로, 붙여넣을 땐 H1 줄은 빼는 게 깔끔하다.)

## 갱신 규칙

- 원본은 어디까지나 `task.md`. 이 폴더는 **파생 요약본**이다.
- 작업이 끝날 때마다 전체를 다시 쓰지 말고, 해당 페이지의 표 한 줄 / 타임라인 한 항목만 고친다.
- 기준일은 각 파일 상단에 적혀 있다. 갱신하면 그 날짜도 같이 바꾼다.
