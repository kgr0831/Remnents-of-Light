# 데모 스프린트 플랜 (2026-08-10 확정)

> 4일 개발 + 별도 QA/빌드일. 3일에서 시작해 논의 중 4일로 확장됨.

## 게임 플로우 (전체 데모 흐름)

1. **오프닝 씬** — 다른 스프라이트로 시작
2. **튜토리얼 맵 진입** — 별도 신규 제작 맵. "카타나 전투 모듈" 재사용. 설정상 **사이버 공간 시뮬레이션 훈련**(실제 상황 아님)이라는 프레이밍. 진입 시 스프라이트가 현재(글리치 사무라이) 스프라이트로 전환
3. 조금 이동하며 **게헨나 포식견**과 전투
4. **튜토리얼 보스** 등장 → **추격 씬** 재생
5. 추격을 따돌린 직후, 플레이어 왼쪽 상단 천장이 부서지며 **거미 보스(The Tarnished Widow)** 등장 컷씬
   - 근거: `전체_몬스터_기획.md` — "게헨나의 거미줄 지대를 지배하는 여왕 거미 보스"
6. **보스 전투** 시작 (거미 보스)
7. **보스 처치 컷씬** 재생
8. **암전** → 데모 종료
